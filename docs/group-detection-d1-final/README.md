## Численная пригодность B

У всех групп ранг 10, PSD covariance и конечные D². Удаление координат и ridge не требуются по этой диагностике. Максимальная относительная ошибка C C⁺ C ≈ C: 1.06e-14; расхождение covariance Welford с независимым centered NumPy covariance: 2e-15. Все eigenvalues и singular values сохранены в JSON; абсолютные величины сырых covariance имеют смешанные единицы, κ приводится после нормализации.

Алгебраическая пригодность не доказывает статистическую достаточность: это один 8-часовой фрагмент и in-sample calibration. Lag-1 correlation по 160 group-vector координатам лежит в диапазоне [-0.138, 0.835]. 2880 ticks нельзя считать 2880 независимыми повторениями. Предельное N≥11 выполнено, междневная устойчивость неизвестна. Go-паритет чисел ещё не проверялся: Go-критерии до согласования не реализованы.

## MAD floor: арифметика и физический смысл

R: 4 из 1440 host-channel MAD равны нулю и требуют floor; все четыре относятся к GPU mean temperature. B: 0 из 160 scales floored, минимальная scale=0.01289210. Поэтому floor не влияет на B этого D1. Число 1e-4 дано отдельно в W/°C, оно не безразмерно и не равно разрешению/погрешности сенсора.

Значения z конечны: наблюдаемого overflow нет. Но нулевой MAD создаёт чувствительность к малому отклонению от массового значения. Пример: 0.01 °C / 1e-4 °C = 100; это не свидетельство физической опасности. Минимальная наблюдаемая spacing в JSON — свойство float32/агрегации, не доказанное разрешение датчика. Second-largest требует двух разных хостов, поэтому один высокий z сам по себе не определяет R. Floor сохранён без изменения; его принятие как научного соглашения остаётся вопросом контрольной точки.

## Воспроизведение

Из корня репозитория, в существующем окружении с NumPy 2.3.5 и PyArrow 26.0.0:

```powershell
python tools/groupdiagnostics/d1.py --output <NEW_DIRECTORY>
python tools/groupdiagnostics/report.py --input <NEW_DIRECTORY>
python -m pytest -p no:cacheprovider tools/groupdiagnostics/test_d1.py
```

Выходные файлы создаются эксклюзивно. Новые пути/code commit в manifest могут отличаться; численные groups, feature distributions и входные SHA должны совпасть в том же окружении. D3 не загружается для вычислений.
