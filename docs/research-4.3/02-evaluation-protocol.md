# Дополнение протокола этапа II, до расчёта H2

14.10.2026. H1/H2 утверждены пользователем в этом чате; H3 остаётся условной.
Исходные формулы и пороги в `02-hypotheses-protocol.md` не меняются.
Ветка `research/h1-h2-comparison-4-3` от aa509f6 (этапы 0/I).

1. Входы — хешированные D1/D2 экспорты и окончательные events/summary/audit
этапа I (`research43-v4`). Заморожены 6978 событий, 6050 пар и 928 unmatched;
контрольные центры не подбираются заново. Все 10-секундные состояния не объявляются
независимыми событиями. D3, H3, production LocalResult/GroupEvent не используются.
2. H1 выводит исходный A0 score и B1 context отдельно. Context должен точно
совпасть с B1, absolute — с A0; OR и совместный бинарный локальный сигнал запрещены.
Для группового анализа H1 используется только context; absolute остаётся диагностикой.
3. H2 обучает только median/MAD/floor и Q99.5 двух направлений на D1. Дельта
определена при непрерывных доступных 7 наблюдениях с шагом10с. Первые6 состояний
каждого окна undefined (для основной оценки не используется перенос через границу
окон); denominator H2 и baseline приращений — только определённые дельты.
Все primary event/control pre60 окна лежат после этого участка; это будет проверено.
4. Simple power baseline: |Δ60 GPU/CPU/PSU|>соответствующий pooled D1 Q99.5,
тот же вариант этапа I. Помимо общего baseline описываются знаки. H2+ и H2−
хранятся отдельно; H2 any — исключительно диагностическое объединение направлений
этой гипотезы, не объединение с H1 и не окончательная модель.
5. Primary: fresh onset в [t,t+120], pre60 без соответствующего сигнала.
Вторичный identical-risk-set: обе стороны пары без сигнала в pre60. Поскольку
условие зависит от метода, размеры risk sets у методов могут различаться.
Дополнительно сравнить B1/B2/H2/P на пересечении risk sets всех этих методов.
Any, preexisting, post-onset, continuous change without crossing, latency/run
duration и H2 power direction приводятся раздельно. Окна 30/60/120/old сохранены.
6. Качество matching — |Ppre,event−Ppre,control|/max(|Ppre,event|,1W)
доминирующей подсистемы. Фиксированные strata ≤1%, (1%,5%], >5%; primary
включает все пары без фильтрации по качеству. Представить matched/unmatched
раздельно по категориям, хостам, амплитуде и предшествующему режиму. No rematching.
7. Bootstrap paired difference: 1999 PCG64 seed4301, whole host и общий час,
30-мин блоки sensitivity. CI описательные, не IID строк и не объективная
точность отказов. Нет подтверждающих p-values для множества этих условных таблиц.
8. Методы: A0 historical (справка), A0 D1-Q99, B1 (=H1 context), B2,
Power, H2+, H2−, H2 any. H1 не является независимым дополнительным детектором.
Основное permutation семейство: 8 методов ×2 статистики (внутригрупповые
pair-bins сигналов и pair-bins новых onset) =16, Holm alpha.05, 1999 одинаковых
случайных разбиений по18 хостов, PCG64 seed4202. Ряды хостов не сдвигаются;
частоты и общая активность сохраняются. Те же seed/разбиения не создают нового
независимого реального испытания. Для старых методов сверить draws с №4.2.
9. Перестановки рассчитываются также через co-occurrence матрицу XᵀX;
проверяется тождество прямому суммированию k(k−1)/2. Сумма E² при равных
группах определяется pair-bins и общей активностью, поэтому не объявляется
дополнительной независимой гипотезой. Вклад четырёх a02 и отношение без них
приводятся описательно, без расширения подтверждающего семейства.
10. Групповые описательные состояния: K_g≥2 и E_g>0, а синхронное новое
изменение — ≥2 onset в группе и положительный onset-контраст с остальными.
Показываются support, contrast, длительности последовательных состояний,
доля групп/кластера. Это диагностика локализации, не рабочий GroupEvent,
не новый калиброванный групповой порог и не доказанная неисправность.
11. Равные бюджеты: 0.5/1/2% общего набора определённых Δ60 состояний D2
(первые6 исключены для всех методов в этом анализе). Stable sort, floor(K).
Ranking A0 — score; B1/H1 — score−hostθ; B2 — score;
Power — max_j |ΔP_j|/Q99.5_j; H2 any — max(u+,u−), направления сохраняются.
Top-K исключительно D2 диагностическое ранжирование, не рабочая калибровка.
Сообщить разрывы ties и threshold budget отдельно. Нельзя выбирать победителя
по F1_ref Mahalanobis; он только вспомогательный статистический контроль.
12. Устойчивость: 8 общих часовых блоков; старые парные IF seeds42/43/44
из сохранённого экспорта. H1/H2/Power детерминированы; bootstrap seeds не являются
seed модели. Дополнительных IF обучений нет.
13. Измерения: один прогрев, пять повторов последовательных вычислений
калибровки/применения каналов и групповой агрегации. Время чтения/записи отдельно,
пиковая память процесса и размеры профилей; scoring сохранённых A0/B2 лесов
измеряется отдельно от расчётов по кешированным score. Старые timing не выдавать
за сопоставимый новый benchmark. Это цена исследовательских кандидатов, не VI.
14. Необходимость H2 оценивается по дополнительной информации/дублированию,
реальным контролям, топологии и стоимости. Увеличение доли совпадений с
приращениями, определяющими выбор событий, само по себе не подтверждает пользу.
При отсутствии преимущества оставить простой вариант. Все отрицательные
результаты и ограничения отражаются в 02-model-comparison.md. После II — остановка
на контрольной точке №3 по текущему уточнению пользователя.
