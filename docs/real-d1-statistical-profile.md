## Обучение и результаты

Обучение использует только D1 `[2022-01-18T00:00:00Z,2022-01-18T08:00:00Z)`:
**829 440 полных конечных F18**. D2/D3 используются только для применения
замороженного профиля и проверки WindowReader. PostgreSQL источником не является.
Новые Parquet и большие промежуточные файлы не создаются.

Формулы (8)–(14) §§2.3–2.4 компонентной РПЗ реализованы прежним ядром:
18 медиан/MAD, `max(1.4826*MAD,0.0001)`, нормализация, средний вектор,
ковариация с `n−1`, Gonum SVD с относительным допуском `1e−12`, квадрат
расстояния и обратная эмпирическая CDF уровня 0,99. Метка использует строгое `>`.

## Численная проверка и сохранение

Профиль `results/statistical-20220118-8h-v1.json` имеет размер **27 905 байт**
и исключён из Git. SaveNew отказывается перезаписывать существующий результат.
LoadProfile проверяет метаданные, конечность, PSD ковариации, ранг и соответствие
псевдообратной тому же SVD-допуску. Отрицательное переполнение квадратичной формы
отклоняется до подавления погрешности округления.

После загрузки все параметры точно совпали с JSON stdout того же исходного
запуска. На 16 фиксированных строках D1 повторно проверены нормализация,
расстояния и метки; результаты совпали точно, профиль не изменился.
Индексы строк: 0, 17, 18, 287, 288, 10000, 100000, 200000, 300000,
414720, 500000, 600000, 700000, 800000, 829422, 829439.

Независимая проверка NumPy 2.3.5 / PyArrow 26.0.0 прочитала все состояния D1
и пересчитала статистики без D2/D3. Медианы/MAD/масштабы совпали с допуском
1e−12; максимальные абсолютные расхождения: средний вектор 8.12e−13,
ковариация 2.89e−13, псевдообратная 9.19e−12, порог 2.56e−13.
Число срабатываний совпало: 8 294. Проверка заняла 3.164 с.

Проверки постоянных и зависимых признаков, полного/нулевого ранга, SVD cutoff,
строгой границы порога, переполнения, повреждённого конечного профиля,
сохранения/загрузки и исключения D2/D3 находятся в Go-тестах.

## Воспроизведение

Из корня репозитория, с доступным существующим Parquet и новым именем результата:

```powershell
go run ./cmd/nir --input data/prepared/summit-D1-pilot/D1.parquet --manifest data/prepared/summit-D1-pilot/manifest.json --output results/statistical-new-run.json --covariance-ddof 1 --svd-rcond 1e-12
$env:NIR_REAL_PARQUET=(Resolve-Path data/prepared/summit-D1-pilot/D1.parquet).Path
go test -v ./internal/experiment -run TestRealPreparedDayWindows -count=1
```

Для `TestRealStatisticalProfileReload` дополнительно задать `NIR_REAL_PROFILE`
(сохранённый Stage A JSON) и `NIR_REAL_ORIGINAL` (JSON stdout того же успешного
запуска). Он сравнивает параметры, повторно читает фиксированные строки D1,
проверяет расстояния/метки, ранг, MP-невязку и среднее `D²` с учётом `n−1`.
Отсутствие opt-in переменных — явный SKIP, не подтверждение реальной проверки.
